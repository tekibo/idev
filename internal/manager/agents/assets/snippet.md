## iOS on Linux with idev

`idev next` shows the setup state and the exact next command. Read the `idev`
skill before building, running, signing, shipping, or touching a device.

- SwiftUI: `idev swift run`, `idev ship`
- Expo / React Native: `idev expo run:ios`, `idev rn run-ios`
- Flutter: `idev flutter build`, `idev flutter ship`
- KMP: `idev kmp`
- Devices: `idev devices --json`, `idev install-app`, `idev launch-app`
- iPad screen: `idev ipad-screen`

Ask before changing host packages. Never ask for an Apple ID password, 2FA code,
or API key in chat. Xcode.xip is user-supplied.
